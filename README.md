# Excel Training for BMN Assistants

## Overview
This project demonstrates the use of Microsoft Excel for managing and analyzing State-Owned Assets (Barang Milik Negara/BMN) data as part of practical training for BMN administrative tasks.
The project focuses on organizing asset data, applying Excel functions, and presenting information in a structured and easy-to-understand format.

## Key Features
* BMN data management and organization
* Data cleaning and preparation
* Excel formulas and functions
* Data analysis and summarization
* Dashboard and data visualization

## Tools
* Microsoft Excel

## Skills Demonstrated
* Microsoft Excel
* Data Analysis
* Data Management
* Data Cleaning
* Data Visualization
* Dashboard Development

## Purpose
This project was created as an Excel training exercise for BMN Assistants to demonstrate practical skills in processing, analyzing, and presenting asset data using Microsoft Excel.

## Disclaimer
The data used in this project is intended for training and portfolio purposes. It does not represent official BMN records or official government reporting.
